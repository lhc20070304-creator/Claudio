# macOS 启动超时排查

## 启动超时修复 · 2026-10-31 10:54:20（Asia/Shanghai）

用户报告 Claudio 启动失败。最新启动日志为 `网易云 API startup cancelled or timed out`；3000 和 8080 都未监听。原 npm 入口先等待匿名登录，再等待 npm 版本检查，均在监听端口之前；外网缓慢时会超过桌面壳的 30 秒启动期限。

修复：新增 macOS 专用 `macos/netease.cjs`，复用已有匿名 token；缓存缺失时在子进程中刷新，最多 5 秒后停止该子进程并继续启动本地 API。关闭启动时版本检查，本地服务仅监听 127.0.0.1。`macos/runtime.py` 改用该入口。Windows 与 node_modules 源码未改；网络不可用时实际搜歌/登录仍需要网络，不代表离线功能。

后台实测：真实 Node + Flask 1.08 秒就绪；网易云搜索与 Flask `/api/taste` 通过；停止后 3000/8080 释放。新增测试覆盖已有缓存不联网、匿名刷新永不返回仍可启动；6 项原有生命周期测试通过。没有打开窗口，GUI 启动待用户再次双击验证。
