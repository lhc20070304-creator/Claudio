# 我的日常节律

## 工作日
- 07:00 起床 — 需要提神但不吵闹的音乐
- 09:00-12:00 深度工作 — 纯音乐/古典
- 12:00-13:00 午休 — 安静的钢琴曲
- 14:00-18:00 下午工作 — Chillhop/Lo-fi
- 20:00-22:00 晚间放松 — 爵士/Bossa Nova
- 23:00-00:00 睡前 — 极简钢琴/环境音乐

## 周末
- 09:00 自然醒 — Bossa Nova
- 15:00-17:00 下午茶/阅读 — 民谣/后摇
- 21:00-23:00 晚间 — 电影原声

## 特殊场景
- 下雨天 → 偏 melancholic 的纯音乐或后摇
- 心情不好 → 温暖的 jazz piano
- 需要专注 → 无歌词的极简电子
