# 情绪 → 音乐 映射规则

## 用户说…
- "累了" / "好累" → 温暖的爵士钢琴，bpm < 100
- "开心" / "心情好" → 轻快的 Bossa Nova，bpm 100-130
- "难过" / "不开心" → 治愈系后摇，先从低沉开始，慢慢上扬
- "烦躁" / "压力大" → 极简钢琴/环境音乐，不要人声
- "想安静" → 纯音乐，音量建议降低
- "来点有精神的" → 古典交响乐或轻快的民谣

## DJ 自行判断（无需用户明说）
- 深夜 (22:00+) → 默认安静模式
- 雨天 → 默认 melancholic 模式
- 刚播放完高能量歌曲 → 缓慢过渡
- 连续工作 2h+ → 建议休息 + 轻松音乐

## segue（转场）规则
- 两首风格跨度大的歌之间，找过渡曲目
- 调性相近 (e.g. C大调 → G大调)
- BPM 缓慢变化（±20 以内为好）
- 情绪弧线：高 → 中 → 低 → 中 → 高
